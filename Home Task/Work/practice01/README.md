# Практическая работа 01 — Каталог товаров

## Как запустить

База данных MongoDB и Docker должны быть установлены. Все команды выполняются из корня репозитория (там, где находится файл docker-compose.yml).

1. Сбросьте базу данных до исходного состояния (21 товар, 120 заказов):  
    docker compose run --rm reset
    
2. Запустите скрипт с решением (он выполнит обе задачи и выведет отчёт):  
    docker compose run --rm python work/practice01/solution.py
    
3. Запустите скрипт самопроверки, чтобы убедиться, что база данных изменилась правильно:  
    docker compose run --rm python practice01/check.py
    
Это способ подходит для обычного пользователя, однако у меня docker и MongoDB развернуты на виртуальной машине, поэтому кратко расскажу как подключение идёт у меня.

- База данных развернута на виртуальной машине и доступно по Ip(У меня статически 192.168.0.222:27017/)
- Поднимаем контейнеры: `docker compose up -d`
-- Сбрасываем базу: `docker compose run --rm reset`
- Перед запуском скриптов убеждаемся в наличии связи с ВМ с помощью команды `ping Ваш Ip`
- Так как база может находится на другой машине, при запуске скриптов мы явно передаем IP-адрес через переменную окружения `MONGO_URI`
